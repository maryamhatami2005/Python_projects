# Number to Words Converter

A simple Python program that converts positive integers into their equivalent English words.

### Examples

```text
Input: 257
Output: Two Hundred Fifty Seven

Input: 600000
Output: Six Hundred Thousand

Input: 3890
Output: Three Thousand Eight Hundred Ninety

Input: 1000000
Output: One Million
```

### Project Structure

```text
.
├── README.md
└── src
    ├── main.py
    ├── test.ipynb
    └── constants.py
```

### Requirements

* Python 3
* No external libraries required.

### How to Run

```bash
cd src
python main.py
```

Enter a number when prompted. The program supports numbers up to 12 digits.
